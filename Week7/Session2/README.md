# Week 7 – Session 2: Azure AI Speech

Hands-on demos for Azure AI Speech — Text-to-Speech (TTS), Speech-to-Text (STT), and Speech Translation using the Azure Cognitive Services Speech SDK.

---

## Setup

### 1. Install dependencies
```bash
pip install azure-cognitiveservices-speech python-dotenv openai playsound3
```

### 2. Configure credentials
Copy the example `.env` file and fill in the keys — **the instructor will share these in class**:
```bash
cp .env.example .env
```

| Variable | Used by | Description |
|---|---|---|
| `SPEECH_KEY` | 1 | Speech resource key (or Foundry multi-service key) |
| `FOUNDRY_KEY` | 2, 3, 4 | Key from your Azure AI Foundry resource |
| `SPEECH_REGION` | 1, 2, 3, 4 | Azure region e.g. `australiaeast` |
| `AZURE_OPENAI_SPEECH_ENDPOINT` | 5, 6 | Azure OpenAI resource endpoint (East US 2) |
| `AZURE_OPENAI_SPEECH_KEY` | 5, 6 | Azure OpenAI resource key |

---

## Scripts

| # | Script | What it does |
|---|---|---|
| 1 | `1_SpeechSynthesis.py` | Type a message → saved as `greeting.wav` (TTS); transcribe `.wav` files in `messages/` back to text (STT) |
| 2 | `2_SpeechSynthesis_Foundry.py` | Same TTS + STT demo using the Foundry multi-service key |
| 3 | `3_CustomerServiceBot.py` | Live mic demo — keyword-based voice bot that detects intent and responds with a neural voice |
| 4 | `4_PocketTranslator.py` | Speak English into the mic → translated and spoken aloud in Japanese, French, Spanish, Hindi, or Chinese |
| 5 | `5_GenerateSpeech_GPT.py` | Instructable TTS — tell `gpt-4o-mini-tts` HOW to speak (tone, emotion, language) and it generates `speech.mp3` |
| 6 | `6_TranscribeAudio_GPT.py` | Transcribes `speech.mp3` (generated by script 5) using `gpt-4o-mini-transcribe`; plays the file first then prints the text |

```bash
python 1_SpeechSynthesis.py
python 2_SpeechSynthesis_Foundry.py
python 3_CustomerServiceBot.py
python 4_PocketTranslator.py
python 5_GenerateSpeech_GPT.py
python 6_TranscribeAudio_GPT.py  # run after script 5
```

> Scripts 3 and 4 require a microphone. Say **"Goodbye"** to exit script 3; type **"quit"** to exit script 4.
> Script 6 requires `speech.mp3` — run script 5 first to generate it.
